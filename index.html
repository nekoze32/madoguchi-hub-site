madoguchi-hub

運営者が自分のためだけに使う、個人用の作業の窓口アプリです。運営者本人の Gmail と Slack に届いた連絡のうち、返事が要るものを作業一覧にまとめ、返信の文案を用意します。メールを送るのは、運営者が画面の送信ボタンを押したときだけです。

一般向けの公開や利用者の登録はしていません。

プライバシーポリシー ／ 利用規約

問い合わせ：github.com/nekoze32

madoguchi-hub is a personal assistant app used only by its operator. It collects messages that need a reply from the operator's own Gmail and Slack into a task list and prepares reply drafts. Mail is sent only when the operator presses the send button. It is not offered to the public.

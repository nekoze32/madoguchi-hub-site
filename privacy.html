madoguchi-hub プライバシーポリシー

最終更新日：2026年10月22日

このアプリについて

madoguchi-hub は、運営者が自分のためだけに作って使っている個人用のアプリです。運営者本人のGoogleアカウント以外では使いません。一般の利用者の登録や、ほかの人のデータを扱うことはありません。

読むデータ

Google の許可（OAuth）を通して、運営者本人の Gmail について次のものを読みます。

  • 受信したメール（送り主・宛先・件名・本文・日時・ラベル）
  • メールボックスの変化の記録（新しく届いたメールを知るため）

権限は gmail.readonly（メールを読む）と gmail.compose（下書きを作る・送る）だけです。

データの使い道

  • 新しく届いたメールのうち、返事が要るものを見分けて、運営者の作業一覧（タスク）にする
  • 運営者が頼んだときに、返信の文案や下書きを作る
  • 運営者が画面の送信ボタンを押したときだけ、そのメールを送る

広告・販売・第三者への提供・ほかの目的には使いません。

データを置く場所と扱い

  • メールの内容と許可の鍵は、運営者本人のパソコン（自宅のMac）の中だけに置きます。外部のサーバーには置きません
  • 返事が要るかの判断と文案づくりのために、メールの内容を AI のサービス（Anthropic の Claude、OpenAI の Codex）に送ることがあります。送るのは処理に要る部分だけで、パスワードやトークンらしい文字列は送る前に伏せます
  • 許可の鍵は運営者本人だけが読めるファイルに置き、画面や記録には出しません

Google API Services User Data Policy への準拠

madoguchi-hub が Google API から受け取った情報の利用と、ほかのアプリへの移転は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

データの消し方・許可の取り消し

運営者は、Google アカウントの「サードパーティ製のアプリとサービス」から、いつでもこのアプリの許可を取り消せます。取り消すと、アプリは Gmail を読めなくなります。パソコンの中のデータは、運営者がアプリのデータを消すことで消えます。

Privacy Policy (English summary)

madoguchi-hub is a personal app built and used only by its operator, with the operator's own Google account. It reads the operator's Gmail (gmail.readonly) to find messages that need a reply and turn them into tasks, and creates drafts or sends replies (gmail.compose) only when the operator presses the send button. Data is stored only on the operator's own computer. Message content may be sent to AI services (Anthropic Claude, OpenAI Codex) to classify messages and draft replies; secrets such as passwords are masked first. Data is never sold, used for advertising, or shared with others. The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at myaccount.google.com/connections. Contact: github.com/nekoze32
